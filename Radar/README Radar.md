The MATLAB and Python scripts in this directory are used as follows:

1. readDCA100.m — A function provided by Texas Instruments (TI) to read the .bin binary file generated by the DCA1000EVM data capture board.

2. RD_VideoOnly_Final_v2.m — Generates a video concatenating the Range-Doppler maps across all collected data frames, which is subsequently cross-verified against the dashcam footage recorded during the data collection runs.

3. RD_ClickExport_Final_v2.m — Extracts frame-by-frame range and velocity information of the following vehicle of interest across the frames during which it was following the sensor-equipped vehicle.

4. range_doppler_smoothing_kf.py — Applies a linear Kalman filter to smooth the raw range and velocity measurements extracted in step 3, mitigating spurious frame-to-frame jumps caused by fluctuations in the spatial extent and intensity of peaks in the Range-Doppler map.
